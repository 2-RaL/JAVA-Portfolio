# JAVA Projects

All projects in this repository are written in the **Java programming language**. The repository is created to collect Java practice projects in one place and to support step-by-step improvement from basic to more advanced programming skills.

## About This Repository

This repository contains different Java projects organized in separate folders. Each project may include Java source files, project configuration files, and, when necessary, its own `README.md` file.

The main purpose of this repository is to keep Java projects structured, easy to access, and ready for future development.

Under this repository, **basic, intermediate, and advanced-level projects** are included. These projects are grouped according to their difficulty level and are intended to help improve Java knowledge gradually.

## Project Levels

The projects in this repository are generally divided into three levels:

### Basic-Level Projects

Basic-level projects are designed for learning the fundamental concepts of Java. These projects usually include simple console applications, variables, data types, conditional statements, loops, and user input with `Scanner`.

### Intermediate-Level Projects

Intermediate-level projects include more structured logic, menu-based systems, methods, data validation, arrays, and simple simulation-based programs.

### Advanced-Level Projects

Advanced-level projects may include more complex functionality such as object-oriented programming, file handling, cleaner code structure, reusable components, and applications that can later be extended with a graphical user interface or database integration.

## How to Run the Projects

To run a project, first open the project folder.

Example:

```bash
cd Calculator
```

Then compile and run the Java file:

```bash
javac Main.java
java Main
```

The main class name may be different in other projects. Therefore, it is recommended to check the `README.md` file inside each project folder.
